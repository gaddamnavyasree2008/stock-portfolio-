# Stock Portfolio Tracker Using Python

## 📌 Project Description
The Stock Portfolio Tracker is a simple Python-based application that helps users track their stock investments. Users can enter stock symbols and quantities to calculate the total investment value based on predefined stock prices.

## ✨ Features
- Displays available stock symbols.
- Allows users to enter stock names.
- Accepts the quantity of shares.
- Calculates individual investment values.
- Displays the total portfolio investment.

## 🛠️ Technologies Used
- Python 3
- Python IDLE

## ▶️ How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open `stock_portfolio_tracker.py` in Python IDLE.
4. Press F5 to run the program.
5. Enter a stock symbol and quantity.
6. Type `DONE` to view the portfolio summary.
